# Arnis 项目记忆

这个目录保存代理协作需要长期复用的项目事实。目标是让下一位代理不必重新摸索目录、构建流程和当前环境状态。

## 使用方式

1. 新任务先读根目录 `AGENTS.md`。
2. 需要系统理解时读 `project-overview.md` 和 `architecture.md`。
3. 准备运行或修改时读 `workflows.md` 和 `invariants.md`。
4. 动手前查看 `current-state.md`，确认资源是否完整、提交是否变化。
5. 非平凡任务完成后，在 `current-state.md` 追加带日期的结果。

## 写作规则

- 只记录已验证事实，猜测要明确标成“待确认”。
- 命令使用项目实际支持的路径与参数。
- 记录会改变后续行为的限制，而不只是记录“做过什么”。
- 不记录令牌、Cookie、个人路径以外的隐私数据或完整日志。
- 不复制大段源码；记录入口函数、模块职责和关键约束。

## 文件索引

| 文件 | 内容 |
| --- | --- |
| `project-overview.md` | 产品定位、版本、技术栈和输出格式 |
| `architecture.md` | 端到端数据流、源码模块地图和 GUI 结构 |
| `data-sources.md` | 四档地图数据组合、来源 URL、缓存、许可和 3D 边界 |
| `workflows.md` | 克隆状态、构建、测试、格式化和资源恢复 |
| `invariants.md` | 排序、确定性、并行接缝、离线、格式兼容等约束 |
| `current-state.md` | 当前提交、工作区状态和会话记录 |
